# Notion AI Agent via MCP 🤖📝

An intelligent agent built with Python and the [OpenAI Agents SDK](https://github.com/openai/openai-agents-python) that connects directly to a Notion workspace using the **Model Context Protocol (MCP)**.

## Features ✨
- **Direct Integration:** Uses `@notionhq/notion-mcp-server` to interact with Notion.
- **Agentic Capabilities:** The agent can search pages, read blocks, and draft content within Notion based on user prompts.
- **Secure:** Uses environment variables to protect API keys.
